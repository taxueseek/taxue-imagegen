# 出图验收(verify)

出图之后的**唯一判定入口**。父技能管「怎么画出来」，本子技能管「画出来这张算不算过」。

父技能 `SKILL.md` #3 第 4 步、#5 阈值表、#6 云端后处理都是本子技能的上游引用点；
数值真源仍在父 `SKILL.md` #5，本文件是**流程与判定政策的真源**。

## 0. 为什么验收要独立成一层

出图前的 preflight 只能拦「提示词写错了」，拦不住「模型把 9 格画成 12 格」「纸底泛黄」
「水印没去干净」。这三类只有**看到像素**才能判。而验收本身有独立的纪律：

- 判据必须**可复现**(同一张图两次跑出同一结论，不能靠印象)
- 判据必须**有出处**(每个阈值能回答「谁在多少张图上实测的」)
- 误报的代价必须**低于漏报**(假 blocker 会逼出一次重生 = 再扣 5–10 积分)

这三条决定了验收不能散在出图流程里，得是一个有自己规则与证据的地方。

## 1. 一次调用(默认路径)

```bash
PY=${PY:-python3}
PY scripts/postcheck.py 图.png --track A --top --text ok --note '版本/场景'
PY scripts/postcheck.py 图.png --track E --expect-cells 9 --text ok
```

一条命令做完四件事，全程 <1s，替代旧流程的 3–4 次往返：

| 做什么 | 产出 |
|---|---|
| 量测 | 白底%/纸底%/泛黄 R-B/饱和度；`--top` 加测顶部留白结构(类型 A 必用) |
| 目检裁片 | 底部文字带 2x 放大 `_textband.png`(类型 A / C)，替代手动裁剪 |
| 水印 | **自动识别**，命中才动手，输出 `_dewm.png` 并复检(见 #3) |
| 记账 | 追加一行 `scripts/logs/runs.csv`(模板调优的数据反馈闭环) |

**文字必须逐字看。** `--text` 不传就是 `pending`，不得计通过；传 `ok` / `bad` 才是结论。
脚本判不了「字对不对」——那要模型看裁片或人看。

## 2. 三档评审(判定口径)

| 档 | 判据 | 动作 |
|---|---|---|
| **blocker** | 量测越界 / 文字 `bad` / 类型 E 格数不符 | 允许**一次**定向重生，只改一项；同一 blocker 修一次仍失败即停 |
| **可修** | 脚本判 pass，但目检见细节软或小构图偏差 | **不重生**；按 #4 决定走云端还是接受 |
| **通过** | 指标在阈值内 + 文字逐字无误 + 水印已清零 | 交付 |

口径差一处必须记住：**脚本的 verdict 只有 `blocker` / `pending` / `pass` 三值**，
「可修」是脚本判 pass 之后由 Agent 目检追加的判定，不写进 runs.csv。

修复纪律：**只改所属那一段指令，禁止堆第二波禁令**(坑 12)。
精确文字两轮仍错 → 转后期排版补字，不假装正确、不同词重试。

## 3. 水印：自动识别，命中才动手

**为什么不能写死。** 水印存在与否由宿主与账号状态决定：有的宿主自动加水印、有的不加、
还可能随会员状态变化。所以「总是去水印」会在干净图上主动改坏画面，
「从不去水印」会把带水印的图直接交付。唯一正确形态是**先识别**。

自动门(`scripts/wm_auto.py`)取 **amp 与 R² 双条件**，这是与报告模式的关键差别：

| | 报告模式(`audit_wm.py`) | 自动模式(`wm_auto.py`) |
|---|---|---|
| 看什么 | 只看 \|amp\| | \|amp\| **且** R² |
| 产出 | 给人看的一行字 | 直接改像素 |
| 判错代价 | 误导 | **改坏一张已经画好的图** |
| R² 低时 | 照报 | 判纹理误报，**不动手也不拦交付** |

三分支：

- **无可见水印**(`|amp| < 1.0`)→ 不碰画面，只记诊断
- **形状确认**(DIRTY 且 `R² ≥ 0.50`)→ 自动去水印 → **复检输出** → 通过才算完
- **存疑**(SUSPECT 区，或高 amp 但 R² 不足)→ 不擅自处理

存疑还要再分一次，这一步是本子技能实测修正出来的：

- `R² ≥ 0.50` → 形状吻合，**但先看这份形状够不够看得见**：`|amp| < 2.0`(≈0.8% 灰度)时
  再跑一次 `dewm_v10.py` 的可见度门控；报「不可解(可见度 < 2.00)」且平白区 std≈0、
  放大裁片无字形 → 判**无可见水印，直接结项**。别为了清掉 pending 去跑 `pick_wm`：
  四版选优只会对一张干净图各自反解出一份噪声，再让你从噪声里挑更少的那个(坑 37)
- `R² ≥ 0.50` 且 `|amp| ≥ 2.0`、目检见字形/署名 → 确实有残留，**记 pending**，
  走 `pick_wm.py` 四版选优或云端 `erase`(平台署名「AI生成 / WORKBUDDY」走 `dewm_imprint.py`，坑 36)
- `R² < 0.50` → 判**纹理/格边误报**，**不拦交付**。让误报逼出返工，正是坑 27 那条教训
  (假 blocker 每张白扣 5–10 积分)

**安全底线：原图永不改。** 输出落 `_clean` 或 `_dewm` 旁路文件(`dewm_io` 守卫)，
去水印后必须重新识别一次输出；复检未通过就保留原图并改走 `pick_wm` / 云端，
绝不把一个更差的结果当成品。近白底上水印「不可解」是正确结论而非失败，不硬解
(硬解会把噪声放大 1/(1−α) 倍)。

## 4. 缺陷在哪，决定怎么修

这张表吸收自 MiMo `image_edit` 的判据，是「少走弯路」最直接的一条：

| 缺陷位置 | 修法 | 为什么 |
|---|---|---|
| **印在画面里**：错字、扇区尺寸错、多一条腿、格数不对、布局崩 | **重生**(`image_gen`，受配额约束) | 编辑工具会**忠实复制它看到的东西，包括缺陷** |
| **缺失或可替换部件**：少个元素、背景不对、错一个字、局部软 | **编辑**(`image_edit` / 云端后处理) | 只动指定区域，已通过的部分不作废 |

两者混用是常见的白费功夫：拿编辑去修印在画面里的缺陷，只会把缺陷原样留着。

云端后处理是**可选项、不默认启用**(父 `SKILL.md` #6)：Agent 不得静默调用，
建议话术须含「修什么 / 代价 / 计费未实测」三点，用户同意后才走。
后处理过的图**必须重跑一次 postcheck**才算通过——enhance/erase 会改变量测指标。

## 5. 各类型的验收重点

数值阈值见父 `SKILL.md` #5(A/B 两列 + C/D/E 豁免与声明值)；这里是「这类图最该盯什么」：

| 类型 | 最该盯 | 已知豁免与陷阱 |
|---|---|---|
| **A 竖版概念海报** | 顶部留白(`--top` 必用)、泛黄 R-B(`base≥240` 判 pending，**先跑 `paper_white.py`** 再考虑重生——重生改不了纸白偏色，坑 33)、文字带逐字 | `top_noise` 只作诊断不判 blocker(纸纹/网点把 std 顶到 30+，13/13 张真图全越线) |
| **B 手绘群像** | 饱和度 ≤70(唯一保留的配色 blocker)；留白偏少看 `near%<40`(且 `base≥200`)——**只提示不判 blocker** | R-B 适用；旧口径 `white%∈[30,65]` 已撤(202 张成品触发 82.2%，evidence.md #4) |
| **C 写实包装** | 品牌堆叠字逐字(有文字带裁片)、版面净空 | 灰底棚拍，**R-B 阈值不适用** |
| **D 叙事分镜** | **尺寸必须 1024x1792**、跨帧角色一致(目检)、逐帧文字/字幕 | **叙事性暖色豁免 R-B**(尾帧黎明必然超阈值)；纹理纸底残留走 `pick_wm`——**v1.13 起评分含结构损伤分，v7 不再「常胜」**：平底区仍可能合法胜出，但纹理纸底有笔画结构处会被罚下(坑 28) |
| **E 多格排版** | **格数 = 声明值**、每格等比例、格间净空 | 「无缝隙、边框像素对齐」是合法变体，此时解析不出净空属正常，**不判 blocker** |

E 的格数校验要显式给 `--expect-cells`(如 `--expect-cells 9`)。
不给就不猜——用户可能声明 9 格也可能 16 格，猜错等于凭空造 blocker。

## 6. 升级与回写

- 翻车与新结论 → 写回父 `references/pitfalls.md` 对应小节(按症状速查)
- 验证过的修复 → **当场回写主模板**(`poster-v5.md` #一 或 `fill_meta` 对应解析逻辑)
- 阈值改动 → 必须同时更新 `evidence.md` 的实测样本量与依据，不许只改数字
- 运行数据由 postcheck 自动写 `scripts/logs/runs.csv`；用 `--no-log` 跑测试与验证，
  避免污染生产记账

**阈值纪律**：任何新阈值都要能回答「在多少张什么图上实测、两组数据分别是多少」。
答不出来就标成诊断值不要判 blocker——本技能已经因为假 blocker 白扣过积分(坑 27)。
