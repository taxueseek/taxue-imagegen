# ImageGen 参数与画幅 · 实测手册

> 实测日期：2026-09-06。所有结论均来自真出图，不是参数文档推测。

---

## 一、参数全表

| 参数 | 必填 | 取值 | 实测状态 |
|---|---|---|---|
| `prompt` | ✅ | 文本描述。**实测英文提示词效果显著优于中文**（群像赛道 15 个角色的清单式描述，中文会丢项） | 常用 |
| `size` | 否 | `WxH` 像素字符串 | ✅ 见第三节，**接受任意尺寸，不止三档** |
| `quality` | 否 | `low` / `medium` / `high` | ✅ `low` 出图正常，构图完整，细节略软；海报/群像正片用 `high` |
| `output_dir` | 否 | 自定义输出目录，默认落在工作区 `generated-images/` | 可用 |
| `footnote` | 否 | 水印文字，≤16 字符（Hunyuan） | ⚠️ **实测无效**：传「踏雪寻仙」后右下角仍是平台「AI生成 WORKBUDDY」合规水印，footnote 未替换 |
| `style` | 否 | 风格描述 | 未实测，模板里已有完整风格段，一般不额外传 |
| `background` | 否 | `transparent` / `opaque` | 未实测 |
| `revise` | 否 | bool，是否改写 prompt（Hunyuan） | 未实测。**两条赛道的模板都是精调过的措辞，建议不要开 revise**，避免被改写掉硬底线 |
| `image1` / `image2` / `image3` | 否 | 图生图输入，本地路径或 http(s) URL | 未实测（本技能两条赛道都是文生图） |
| `input_fidelity` | 否 | 与原图的风格贴合度（仅图生图） | 未实测 |

## 二、出图成本

- 单张约 **5–10 积分**，与 `quality` 关联（`high` 取上限）。
- **硬性要求**：出图前必须告知用户本次预计消耗。批量（≥5 张）先确认再跑。
- 省积分的正确姿势：**先小批量验模板（2 张），确认骨架对了再铺量**。
  v5 九风格那轮一次出 9 张（约 45–90 积分），其中 2 张需要重出——先出 2 张能省下这个损失。

## 三、尺寸实测（2026-09-06，同一 prompt 四组对照）

Prompt：`A flat minimalist test sheet: a single solid vermilion circle centered on a pure white background, no text, no texture, no gradient.`
Quality：`low`

| 请求 `size` | 实际输出 | 画幅 | 文件 | 结果 |
|---|---|---|---|---|
| `1024x1024` | `1024x1024` | 1:1 | 229 KB | ✅ 精确匹配 |
| `1024x1280` | `1024x1280` | 4:5 | 517 KB | ✅ 精确匹配 |
| `1152x1536` | `1152x1536` | 3:4 | 516 KB | ✅ 精确匹配 |
| `1536x1024` | `1536x1024` | 3:2 | 1397 KB | ✅ 精确匹配 |

**四组全部按请求像素精确输出，没有被裁剪、补齐或就近取整。**

佐证：历史归档目录 `~/Pictures/WorkBuddy` 下 54 张 png，其中
`1024x1536` × 46、`1024x1280` × 2、`1536x1024` × 1、`1152x1536` × 1 均为本工具产出且尺寸精确。

> 官方 schema 的 `description` 只列了 `1024x1024 / 1024x1536 / 1536x1024` 三个**示例值**，
> 不是枚举白名单。实测 1024 / 1152 / 1536 三档长边的组合都能过。

### 尚未实测（要用的话先单张探一张）

- `768x1024` / `896x1152` 等 1024 以下的小尺寸
- `2048x2048` 及以上超大尺寸
- 极端长宽比（如 `1024x2048` 1:2、`2048x1024` 2:1）

## 四、画幅怎么选

| 用途 | 画幅 | `size` | 备注 |
|---|---|---|---|
| 概念海报 / 唱片封面 / 书籍封面 | **2:3** | `1024x1536` | 两条赛道的默认。竖向叙事空间最足，顶部 25% 留白最好用 |
| 社媒竖图（小红书封面） | 3:4 | `1152x1536` | 平台原生 3:4，不用二次裁切 |
| 社媒九宫格 / IG | 4:5 | `1024x1280` | 顶部留白从 25% 提到 35%，第三级文字放大一档 |
| 头像 / 方卡 / 播客封面 | 1:1 | `1024x1024` | 尺度反差会被压扁，巨物要缩小 |
| 横版 banner / PPT 背景 | 3:2 | `1536x1024` | ⚠️ 赛道 A 的「巨物 + 顶部留白」逻辑在横幅里失效，构图要重写 |
| 16:9 视频封面 | — | 无原生支持 | 取 `1536x1024` 后期裁上下，或直接在提示词里写 `wide 16:9 composition`（仅影响构图不影响像素） |

### 换画幅时必须同步改的三处

1. **顶部留白比例**：竖版 25%，4:5 提到 35%，横版改成左侧或右侧留白带。
2. **文字三级比例**：`100 : 22 : 12` 是按 2:3 校准的，画幅变窄要放大第三级（否则不可读）。
3. **尺度反差强度**：画幅越方/越横，巨物越容易被边框切掉，主体高度要下调。

## 五、水印与去水印（2026-09-07 实测定稿）

- 每张图右下角固定**两行水印**「AI生成 / WORKBUDDY」，约 111×51 px @1024 宽，距右/下边缘约 10px，位置恒定。
- **工具层面关不掉（均已实测证伪）**：
  - ImageGen schema 没有 LogoAdd/水印开关（`additionalProperties: false`），`footnote` 只能改字面、去不掉平台水印；
  - 51CTO 热文《WorkBuddy生图有水印？一招教你去掉》的方案 A「改 buddy-cloud.py 加 `LogoAdd: 0`」在本版**无效**——
    ImageGen 实际走 `miora_text_to_image` 通道，不经过 buddy-cloud.py（4 份副本全部打补丁后出图照样带水印，已实测并已还原）；
  - 方案 B（自造直连 tcproxy 的无水印技能）也走不通：`BUDDY_CLOUD_TOKEN` 不在 agent 执行环境里，`miora_*` 工具未对 agent 暴露。
- **可用方案 = 本地像素修复** `scripts/rmwm.py`（OpenCV Telea + top-hat 字形掩膜：只修水印笔画，框内留白/纹理/色块保留）：

```bash
PY=/Users/taxuexunxian/.workbuddy/binaries/python/envs/default/bin/python
$PY ~/.workbuddy/skills/taxue-imagegen/scripts/rmwm.py a.png            # 输出 a_nw.png
$PY ~/.workbuddy/skills/taxue-imagegen/scripts/rmwm.py *.png --check    # 只检测不改图
$PY ~/.workbuddy/skills/taxue-imagegen/scripts/rmwm.py *.png --out DIR  # 批量输出到目录
```

  实测三例（修复框内亮度偏离占比，前后）：
  | 场景 | 前 | 后 | 结论 |
  |---|---|---|---|
  | 纯色底 | 0.155 | 0.0000 | 完美 |
  | 纹理底（含划痕细节） | 0.135 | 0.0008 | 完美，纹理全保留 |
  | 水印压在锐利设计元素上（曲线边缘+红装饰条） | 0.381 | — | 水印除净，但边缘毛糙、装饰条被吃 → **这类图改构图重出更划算** |

- **水印有两款（2026-09-07 定稿三步法）**：除常规深灰款外，还有**浅灰反白款**（比纸底亮 1–2 级的灰白字，
  峰值 ~7 级）——`rmwm.py` 的 top-hat 暗笔画掩膜**抓不到**，`--check` 会误报干净，单纯中值替换会残留 ghost，
  纯 Telea 修补会抹平纸纹留下可见平块。**有效流程（实测残留峰值 1.1→0.4，纹理无缝）**：
  1. **定位**：对右下角 ROI 做「有符号偏离块图」（ROI − medianBlur(31)，按 8×8 块求均值），
     浅色水印呈现为一片 +1 左右的结构化亮块，据此锁定精确范围；
  2. **极性掩膜 + Telea**：区域内 `d > 0.8` 掩膜、膨胀 5×5×2，`cv2.inpaint` 半径 3——字迹除净但区域变平；
  3. **纸纹移植**：同图同 y 带找无暗像素的干净源块，`目标 median31 低频 + 源块高频`，边缘 10px 羽化融合。
  纯 PIL+numpy+cv2 即可，无需额外依赖。⚠️ 脚本里 `p.replace("_nw3.png", …)` 这类基于不存在的子串做命名会静默覆写原文件，输出名要显式拼接。
- ⚠️ 合规：水印是 AI 生成内容标识，公开发布请走平台 AI 声明，别去标识当原创。
- 出图后如需归档：`cd ~/Pictures/WorkBuddy && python3 _tools/sync_images.py --apply`
  （按日期分目录、同主题合并、SHA-256 去重、幂等可反复跑）。
