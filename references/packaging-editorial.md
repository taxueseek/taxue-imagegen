# 类型 C · 写实包装 Mockup(编辑风单色油墨)

> v1.9 新增。2026-09-08 三轮实测沉淀：r1(全图网点，产品感不足)、r2(摄影底 + 多色网点插画，5/6 文字正确)、r3(本模板，4/4 逐字全对)。
> 与类型 A 的本质差异：A 管图文关系(一个主体 + 三组文字)，C 管包装表面的**版面设计层**——摄影底是舞台，网点只是印刷图案，二者物理分层。

## 一、元提示词模板(中文，槽位化)

```
棚拍产品包装样机，超写实照片质感，严格【三比四】竖幅。左上方一盏柔和漫射主光，地面有柔和接触阴影与极淡倒影，背景为无缝【浅灰/中灰】素净背景纸。四分之三主视角度，主体占画面约【三分之二/四分之三】高，画面中除产品外无任何道具。

主体：一只【形态+材质+物理细节：褶皱/厚度/贴地承重】。

包装版面（印在【哪个面】）：编辑风【单色/双专色】油墨设计。【纸材/涂层】本色打底，全版面只用【一/两】种专色——【色A】（【+色B】）。版面大量刻意留白。核心元素是一幅大型隐喻图形：【一个隐喻物，一句话说死】，以调幅网点（AM halftone）点绘构成，带正片叠底的叠印效果；网点只出现在这一幅图形内部，紧贴包装表面，【跟随曲面/褶皱/压纹】、压在材质光泽之下。除此之外的画面——背景、光影、材质、文字——全部为连续调照片质感，严禁全图网点滤镜。

品牌字体：巨型堆叠粗体品牌名，分两行自上而下排布——第一行「【词1】」，第二行「【词2】」——压叠在隐喻图形之上，颜色取【色A】专色。品牌名下方一行极小文字「【品类英文】 / 【规格】」。全版面只有以上几处文字，恰好这些字母，不得增减，不得出现其他文字、日期或编号。

负向：不是平面海报，不是全幅印刷滤镜，不是多色照片标签；无霓虹，无塑料感渲染，无水印签名。
```

## 二、槽位表(r3 实测四填法)

隐喻图形选法：**品类属性 → 一个可数、轮廓闭合的单一物体**(烘焙之火→火山；精华一滴→水滴；柑橘→太阳；静夜→月)。禁止选抽象氛围或多个物体并列——r2 用"咖啡枝叶/柑橘剖面"已偏插画拼贴，r3 单一隐喻物版面立刻干净。

## 三、硬规则(实测验证，违反必翻车)

1. **网点只许出现在隐喻图形内部**，其余(背景/光影/材质/文字)写死"连续调照片质感"并双保险负向"不是全幅印刷滤镜"。r1 整图网点 → 平面海报感，产品不存在。
2. **品牌名写法 = 巨型堆叠两行 + 逐字声明**：「第一行『SLOW』，第二行『ROAST』……恰好这些字母，不得增减」。r3 四张 8 个词组全对；r2 多词长句(BITTER CITRUS 一行)糊成 BITT ECTRU。
3. **罐身文字不写"竖排/缠绕"**：单行水平、直读不绕柱面；两行堆叠比一行多词更稳。
4. **避坑联动 preflight**：画幅写「三比四竖幅/portrait」，不写 vertical；材质不用 cream/牛皮纸/warm(坑1)；中文 prompt 约 460–480 字触发坑16提醒(实测可过，报 internal error 再压缩)。
5. **专色命名**用具体墨色名(深焙棕/深靛蓝/墨黑/柠檬黄/骨白)，不用泛形容词；深底反相(炭灰底+骨白墨)实测同样成立。
6. **规格行允许数字**(250G/30ML/330ML)：r3 三张数字全对，包装写实性需要的数字不必禁。
7. **出图串行 + 立即改名**：并行同秒撞名会覆盖(坑17，r2 实丢一张)；本类型 3:4 用 `1152x1536`。
8. **验收口径**(出图前锁死)：①文字逐字 ②网点只在图形内 ③专色≤2+本色打底 ④巨字压图形 ⑤整体写实。量测 R-B 阈值对灰底棚拍不适用，泛黄前兆以目检为准。

## 四、留白与面积

不写百分比(坑3)。用「版面大量刻意留白 + 巨型字体占压 + 主体占画面约三分之二高」三句组合即可，r3 四张留白全部成立。
