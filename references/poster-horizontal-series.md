# 横版海报系列——两支横版母版与它们的已验证风格

> 本文件收**横版**的两支母版（§一–§四 H 系限色平印人物 / §五 复古宣传画木刻版画），
> 它们与 `poster-v5.md`（竖版 2:3）互不通用，彼此之间也互不通用——**骨架不同就不能互相填**。
>
> **§一–§四 · H 系与 `poster-v5.md` 是两支母版，不能互相填。** poster-v5 §一 是**竖版 2:3 + 三级文字**；
> 本系是**横版 3:2 + 巨字横带 + 一条短句块**。骨架不同、槽位不同、出图尺寸不同——
> 把本系的风格名填进竖版母版，或反过来，都会得到挂不上骨架的图
> （§六·戊 曾建议把这批风格「填进 §六 / §六·乙」，那是错的，2026-09-23 盘点纠正）。
>
> 一份骨架 + 11 个槽位 = 无限细分风格，每次只换槽位值，不动骨架。
> 实测基线：WorkBuddy ImageGen（`hunyuan-image-alpha`）、`size=1536x1024`（3:2）。
>
> **两支母版怎么选**：要「人物 + 巨型英文标题」走 §一–§五（H 系）；
> 要「四色木刻 + 美术字 + 红日」走 §六（复古宣传画）。

## 一、骨架（固定，逐字复用）

```

设计一张横版 3:2 概念海报。

【三项输入】
视觉风格：{视觉风格}
内容主题：{内容主题}
表达意图：{表达意图}
表达意图决定主体状态与情绪，不决定画什么。

【版式骨架 · 四层】
1. 顶部留白层：画面最上方约五分之一是连续完整的纸底，只有纸张纤维与极轻的网点，不放任何图形、色块或文字。它是纸底的直接延续，不得画成纸条或任何有边缘的实体。
2. 巨字横带：英文主标题以横排巨型字级横贯画面，字高约占画面高度的四分之一，字被主体与背景元素包围、穿插、局部遮挡，成为画面的结构骨架；每个字母仍完整可辨认。
3. 主体层：{主体形象}，半身构图，占据画面中部偏左，上沿咬入巨字横带，下沿延伸至画面底边；画面中只有这一个人物。
4. 小字块：中文短句与英文短句组成一个紧凑文字块，落在画面左下角的纸底上。

【画面】
围绕一个明确瞬间展开，不把多个概念拼在一起。
{背景元素}
从视觉风格中只取两至三个特点，运用到主体轮廓、画面分区、色块关系或文字排列中，不贴纹样边框。
若参考具体作品，不照搬其中可辨认的角色、物体或场景。
人物不做写实刻画，被几何化为平面色块与硬边剪影，不出现皮肤质感与五官细节。

【工艺】
限色平版印刷：{主色} 与 {强调色} 双色叠印，压在 {纸底色} 纸底上，细密 AM 半调网点、轻微错版与轻微褪色油墨；未涂布纸纤维纹理。
纸底肉眼接近中性，比纯白柔和一档；无渐变、无做旧、无茶渍、无陈旧泛黄、无米黄、无深色边框。

【硬底线】
- 画面中只有一个人物，不出现第二个人物、人形剪影、重复形象或面部
- 主体覆盖主标题单个字母的面积不超过该字母的三成，其余部分保持完整可辨认
- {强调色} 单一连续，覆盖不超过画面百分之八
- 网点与颗粒只在图像内部，不得进入字形外扩十二像素
- 中文短句与英文短句周围留出不少于两个中文字高的纸底，任何图形不侵入
- 顶部五分之一的留白层内不得有任何元素
- 画面任何位置不得出现第二个文字块

【三组文案】
英文主标题：{英文主标题}，逐字母 {主标题逐字母}，巨型横排，字高最大，被元素穿插遮挡
中文短句：{中文短句}，逐字 {中文逐字}，字高约为主标题的四分之一，承担主要阅读信息，完整、清晰、醒目
英文短句：{英文短句}，字高约为主标题的十分之一，呼应中文语义但不逐字直译，正常观看清楚可读
这三组之外，画面任何位置不得出现文字、字母、数字、日期或符号。不添加多余标点，文案不带引号字符。
层级通过字重、位置、间距与对齐建立，不依赖悬殊字号。

【负向】
不出现 logo、水印、相框、样机、二维码。
平面化、非摄影、无写实景深、无廉价 3D、无高饱和荧光色。
场景内的招牌不出现随机字句。

【观看路径】
第一眼看清主体与巨型英文标题；第二眼读中文短句；近看发现与主题有关的印刷细节。
```

## 二、槽位语义（11 个，改这些就等于换一种风格）

| 槽位 | 填什么 | 约束 |
|---|---|---|
| `{视觉风格}` | 流派 + 年代 + 媒介 | 写流派不写具体作品名；两到三个特征即可 |
| `{内容主题}` | 一个抽象名词或一句意象 | 不要写成故事 |
| `{表达意图}` | 一个明确瞬间 / 情绪 | 是场景不是概念（"散场后的第一排空座"而非"孤独"） |
| `{主体形象}` | 单一东方女性形象 + 服饰 + 姿态 | 必须自带"几何化"写法，否则会漂向插画 |
| `{背景元素}` | 氛围层：地景 / 纹样 / 道具 | 只给母题，不给百分比 |
| `{主色}` | 承重色（占大面积） | 单一色相，深色系 |
| `{强调色}` | 唯一强调色 | 单一色相，暖色优先（与冷主色对冲） |
| `{纸底色}` | 纸底描述 | **禁止** warm / ivory / aged / 象牙 / 米黄——是强色相指令，必泛黄 |
| `{英文主标题}` | 单个大写英文单词，6–9 字母 | 多直线字母与负空间；圆润长词会挤爆构图 |
| `{中文短句}` | 7–9 字 | 口语、带画面感，不作格言腔 |
| `{英文短句}` | 一行短句 | 与中文**语义呼应不逐字直译**，视角/时态错开 |

**两条跨风格硬规则**

1. **限色**：全系列只用「主色 + 强调色 + 纸底」三档。多加一色就失去平印质感。
2. **纸底不能写色相词**：参考图的纸底实测 R−B≈26（暖米白），这是模型把「纸」当材质色渲染的结果，提示词压不下来。正确做法是写「未涂布纸白底、比纯白柔和一档」+ 纹理词，出图后用 `scripts/paper_white.py` 确定性归正（免费）。

## 五、H 系实测边界与待办

- **画幅**：平台横版最近的是 3:2（`1536x1024`）；原生参考图是 16:9，需要 16:9 时后期裁切。
- **纸底**：参考图纸底实测 `R−B≈26`（偏暖），是模型把「纸」当材质色渲染的结果，提示词压不下来。
  写法上**不写色相词**，出图后用 `scripts/paper_white.py` 确定性归正（免费）。
- **文案**：11 格的差异轴是「配色体系（冷主色 × 暖强调）× 印刷工艺 × 文化母题」，
  骨架不动，所以 11 张仍是一套。
- 待办：图形规则系统型（§一·丁）与本系骨架尚未合并尝试；本系目前只有「人物半身」一种主体形态，
  换成非人物主体的边界未实测（首次用按探索模式跑 2–3 张）。

## 六、复古宣传画 · 木刻版画（横版 2.5:1，四色限定）

> 与 §一–§四 的 H 系**不是同一支**：H 系是巨字横带 + 限色平印人物（3:2），
> 本支是四色木刻版画 + 厚重美术字 + 红日构图（宽幅约 2.5:1，实测 `1536x768` 精确输出）。
> 素材来自用户提供的 20 世纪 50–70 年代社会主义现实主义宣传画参考图。
> 已验证：台账 `verdict=pass`（2026-09-18，复刻版 1 张，含去水印后处理）。

### 6.1 骨架（槽位版，逐字复用）

```
设计一张横版中国复古宣传画海报，木刻版画风格。

【画幅】
横版宽幅，约 2.5:1 比例。

【整体风格】
中国复古宣传画风格，类似 20 世纪 50–70 年代社会主义现实主义宣传画。
木刻版画质感：粗粝边缘、刀痕块面、块面阴影，网点与颗粒纹理贯穿全图。
字体为厚重美术字，带立体字效与厚重投影。
无现代设计感、无渐变、无光滑过渡、无摄影真实感。

【纸张底色 · 关键项】
白底透微黄——像漂白过的旧纸，非常浅的米白，底色要浅要白。
仅保留极轻的做旧颗粒与色差，不得出现牛皮纸色、褐色、茶色、深米色。

【配色】
全图不超过四种颜色：黑、深绿、白、红。
红色为单一连续色块，只出现在红日、右侧竖条、左侧细线这三处。

【画面布局】
- 左侧：巨大黑色美术字「【主标题】」，两个汉字必须水平并排、不得上下堆叠，
  占据画面左半主要区域，带立体字效与厚重投影
- 左边缘：竖排黑色小字「【左栏文字】」，其左侧一条细红色竖线分隔
- 右上：巨大红色圆日，内部有白色云纹横向切割
- 右下：黑色远山剪影，山顶白色积雪，木刻块面质感
- 中央偏下：【主景】
- 右边缘：红色竖直色条（宽度约为主标题字高的一半），
  条内白色竖排文字「【右栏主词】」，其下方小字「【右栏副句】」

【文字规范】
- 画面中的文字只有上述四组，全部逐字照写，不得增删改、不得错序
- 文字一律使用黑色或白色，不得描边、不得变形、不得加装饰花纹
- 主标题两个字必须水平并排，字面清晰可辨

【质感】
木刻刀痕、粗粝边缘、网点颗粒、块面阴影；
纸张有极轻的做旧颗粒，但整体干净明亮。

【负向】
不要现代设计感；不要摄影真实感；不要明亮饱和的现代配色；
不要渐变背景；不要深色背景；不要牛皮纸色 / 褐色 / 茶色；
不要写实光影与柔焦；不要细线描边；不要 logo、签名、日期、编号、网址。
```

### 6.4 本支边界（实测）

- **画幅**：宽幅约 2.5:1，平台按 `1536x768` 精确输出（与 H 系的 3:2、v5 的 2:3 都不同）。
- **纸底是「关键项」**：源提示词专门用一节写它（白底透微黄、要浅要白），
  并显式禁掉牛皮纸色/褐色/茶色——这是四色木刻最容易翻车的地方。
- **红色只许出现在三处**（红日、右侧竖条、左侧细线），写成可数约束而不是「少量」。
- **文字只有四组**（主标题 / 左栏 / 右栏主词 / 右栏副句），逐字照写、不得增删改序；
  主标题两个汉字**必须水平并排**（这条被单独重复了两次，说明踩过）。
