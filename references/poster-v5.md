# 类型 A · 竖版概念海报（v5 融合版，当前推荐）

> 核心难题：**图文关系**与**尺度反差**。
> 默认输出 `1024x1536`（2:3）。默认 `quality=high`。

---
## 一、v5.4 模板全文（v5.1 补丁、v5.2 文案写法、v5.4 逐字声明/竖排保护/浅灰禁令已并入；复制后填空，整体作为 prompt 提交）

```
设计一张竖版 {比例，默认 2:3} 概念海报。

【三项输入】
视觉风格：{视觉风格}
内容主题：{内容主题}
表达意图：{表达意图}
表达意图决定主体状态、元素关系与情绪，不决定画什么。

【画面】
围绕一个明确的瞬间或一组形象关系展开，不把多个情节或概念拼在一起。
主体：{主体形象}。其状态与动势由表达意图决定。
从视觉风格中只取两至三个特点，运用到主体轮廓、画面分区、
色块关系或文字排列中，不必全部使用。
让风格体现在画面的组织方式里，而不是贴上纹样、边框或符号。
若参考具体作品，不照搬其中可辨认的角色、物体或场景。
工艺若与视觉来源冲突则改用更适合该风格的材质处理。

【硬底线：以下为数值约束，不可协商】
- 背景：单一均匀纯色 {背景色}。无渐变、无纸纹、无颗粒，
  无米白、奶油、象牙、泛黄、牛皮纸色调，无茶渍与做旧，无浅灰
- 三级文字的字高比例固定为 100 比 22 比 12，第三级在正常观看距离必须可读
- 三级文字统一放在底部文字带内，主体不得与底部文字带重叠，
  每个文字块净空 ≥ 字高的 1/2
- 强调色：单一连续色块，覆盖 ≤ 画面 8%
- 网点与颗粒：仅用于图像内部必要区域，不得进入字形外扩 12px
- 顶部 25% 为连续留白；留白是背景色的直接延续，
  不得被画成纸条、横幅或任何有边缘的实体色块

【软引导：以下交给主题与意图决定，不预设数值】
- 主体与参照物可形成强烈尺度反差，具体倍数由主题决定
- 位置、方向、疏密、间距由表达意图决定
- 不固定左图右字或中央构图

【三组文案】
整张海报里只有一条文字带，它位于画面最底部；下面三组文案全部并且只出现在这条文字带里面，
  画面其余任何位置都不得出现任何文字、字母、数字或符号。
字最大的一行是英文主标题，内容只有 {N} 个词：{英文主标题}，
  这个词在整张海报中只出现一次，除这一处外任何区域不得再出现它
第二行是中文短句，必须恰好是这几个字：{中文短句}
  （依次为：{把这几个字用顿号逐个列出}），一字不多一字不少、字序完全正确；
  承担主要阅读信息，完整、清晰、醒目，表达具体含义，不只是重复英文标题；
第三行是英文短句，内容是：{英文短句}，呼应中文语义但不逐字直译，
  正常观看时清楚可读，不缩成装饰性小字。
主标题若竖排且多于一个词：拆成两个独立竖列左右并列，
  或逐字母声明总数与顺序，且相邻两词的首末字母不得相同。
底部文字带内除三组文案外不得有任何图形、数字、等号、比例符号或其他标注，
  任何图形都不得侵入这条文字带。
三组文案不得包含任何引号字符。
新写的文案不得冒充原作引文。
层级主要通过字重、位置、间距与对齐建立，不依赖悬殊字号。

【负向】
场景内的招牌不出现随机字句。除三组文案外无额外文字、编号、日期或网址。
不显示包裹文案的引号，不添加多余标点。
不出现 logo、水印、相框、墙面样机或手机屏幕展示效果。

【观看路径】
第一眼看清主体与英文主标题；
第二眼通过中文短句理解画面想表达什么；
近看发现与主题有关的细节。
```

> ⚠️ 满铺型主体（巨浪、巨字、沉浸场景）不适用本模板的「纯白背景 + 顶部留白」两条，
> 按 §五「硬底线二选一」改用：场景铺满 + 底部文字带，主动放弃纯白与留白条款。

### 一·乙 · 变体：主标题穿插型（2026-09-07 实测有效）

用户要求主标题穿插于画面而非底部文字带时，在 v5.4 主模板基础上只做三处替换，
其余段落逐字不动：

1. 删掉硬底线中「三级文字统一放在底部文字带内」一条，换成：
   `英文主标题在整张海报中只出现一次：它穿插在画面中部{位置描述}；除主标题外，任何区域不得再重复出现主标题这个词`（坑 14①，不写则约 50% 重复渲染）。
2. 底部文字带改两行制：只放中文短句 + 英文短句；
   比例声明改为 `中文短句字高 : 主标题字高 ≈ 22 : 100，英文短句 ≈ 12`。
3. 主体母题是向上动势（飘带、飞升、展翅）时，不写「不得侵入顶部」禁令，
   直接改写主体动势方向（坑 14B）：`整体动势向下垂落…像一件刚被脱下还没落地的薄纱；所有墨迹的最高点位于画面高度百分之七十以下`。

## 二、填空规则

| 槽位 | 填什么 | 原则 |
|---|---|---|
| `{视觉风格}` | 流派 / 年代 / 媒介 | 写「瑞士国际主义」「1960s 波兰海报」「浮世绘版画」，**不写具体作品名**；写了也只当抽象转译的参照 |
| `{内容主题}` | 一个抽象名词 | 无常、秩序、速度、光、空、通勤、汛期…… |
| `{表达意图}` | 一句话的瞬间或情绪 | 「早上六点，站台上只有我」这类**具体场景**，不是「表现孤独」这种概念 |
| `{主体形象}` | 由主题衍生的单一形象 | 几何化、去细节、去拟人。细节一多就变插画，尺度感立刻垮掉 |
| `{背景色}` | 纯白或指定纯色 | 默认写「明亮纯白（bright pure white），不是浅灰」—— 瑞士风格等会把底色压成浅灰（坑 9，加强写法待单因素验证）。**只能写中性白**，见 pitfalls |
| `{英文主标题}` | 单个英文大写单词 | **6–9 字母最佳**，要有大量直线与负空间（HABITAT / GRID / VOID / FORCE）。太圆太长（SYMPHONY）会挤爆构图 |
| `{中文短句}` | 7–12 字 | 口语短句、带画面感，不作格言腔 |
| `{英文短句}` | 一行短句 | 与中文**语义呼应不是逐字直译**，在时态/视角/意象上错开 |

三条硬规矩：

1. **不逐字直译** —— 中英文案是语义呼应，不是双语对照表。中文给具象画面，英文给抽象余味（或反之）。
2. **字母可辨认** —— 穿插遮挡是结构手段，不是可读性牺牲。
3. **顶部 25% 留白** —— 整张海报的呼吸阀，任何元素（含标题）都不得侵入。
4. **向上动势要换向** —— 主体母题是向上动势（飘带、飞升、展翅）时，「不得侵入顶部」禁令无效；
   改写主体的动势方向（写法见 §一·乙 第 3 条，坑 14B）。

## 五、满铺型主体的硬底线二选一（2026-09-06 实测结论，操作段）

「背景纯白 + 顶部留白」这两条硬底线**只对孤置型主体成立**。
满铺型主体（巨浪、巨字场景、充满画面的结构）会天然突破：实测浮世绘巨浪把海面铺满下半部、
浪顶侵入顶部留白带（top noise 94.9），背景纯白条款失效。

按主体类型二选一，不能两者都要：

| 模式 | 硬底线组合 | 适用 |
|---|---|---|
| 孤置型 | 纯白背景 + 顶部留白 + 底部文字带 | 巨物/单体/极简 |
| 满铺型 | 场景铺满 + 底部文字带（**放弃**纯白与留白条款） | 巨浪、巨字、沉浸场景 |

## 七、这套模板最适合哪些场景

### 🟢 最适配

| 场景 | 为什么 |
|---|---|
| 展览 / 双年展 / 艺术节主视觉 | 巨物 + 巨字的纪念碑感天生是展览语言；三组文案层级正好对应「主题—阐释—英文索引」 |
| 独立杂志封面与内页专题 | 顶部 25% 留白留给刊名，底部小字留给期号 |
| 专辑 / 演出 / 概念 EP 封面 | 2:3 就是唱片比例；「安静而有力量」正是独立音乐视觉调性 |
| 品牌 Campaign 的 KV 主图 | 双色调易延展到物料系统；无 logo 约束反而方便后期叠品牌位 |
| 书籍封面（社科 / 哲学 / 科幻） | 抽象母题不剧透内容，尺度反差制造「大主题下的个体」隐喻 |
| 概念电影 / 剧集海报（非卡司向） | 适合氛围先行的文艺片、科幻片前期宣发 |
| AI 图像风格基准测试 | 模板变量固定、结构稳定，适合横向对比不同模型对同一母题的还原力 |

### 🟡 可用但需调整

| 场景 | 调整建议 |
|---|---|
| 社媒九宫格 / 手机海报 | 改 4:5 或 1:1；顶部留白 25% → 35%；第三级文字放大一档 |
| 需要放 logo 的商业稿 | 在顶部留白预留 logo 位，别让巨物顶到天头 |
| 横版 Banner / PPT 背景 | 构图逻辑要重写 —— 尺度反差在横幅里会失效 |

### 🔴 不适用

- 需要真实产品图、人物肖像、美食、衣物的**实拍向**物料（模板强制「无摄影感」）
- 需要 QR 码、日期、地点、票价的**活动执行稿**（模板显式禁掉）
- 高饱和、热闹、促销感的设计（气质相斥）

## 八、使用心得

- **主标题选词决定成败**：6–9 字母、大量直线与负空间的词穿插效果最好。
- **巨物要去细节**：越几何化，穿插时越像建筑结构。
- **极小参照物放主画面之外**，塞进巨物里尺度反差会被吃掉。
- **工艺指令要留退路**：模板里「若与视觉来源冲突则改用更适合该风格的材质处理」这句很关键 ——
  它让敦煌、浮世绘这类非西方印刷传统的母题不会硬套 AM 网点而变廉价。
