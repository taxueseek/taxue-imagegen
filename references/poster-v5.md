# 类型 A · 竖版概念海报（v5 融合版，当前推荐）

> 核心难题：**图文关系**与**尺度反差**。
> 默认输出 `1024x1536`（2:3）。默认 `quality=high`。

---
## 一、v5.4 模板全文（v5.1 补丁、v5.2 文案写法、v5.4 逐字声明/竖排保护/浅灰禁令已并入；复制后填空，整体作为 prompt 提交）

```
设计一张竖版 {比例，默认 2:3} 概念海报。

【三项输入】
视觉风格：{视觉风格}
内容主题：{内容主题}
表达意图：{表达意图}
表达意图决定主体状态、元素关系与情绪，不决定画什么。

【画面】
围绕一个明确的瞬间或一组形象关系展开，不把多个情节或概念拼在一起。
主体：{主体形象}。其状态与动势由表达意图决定。
从视觉风格中只取两至三个特点，运用到主体轮廓、画面分区、
色块关系或文字排列中，不必全部使用。
让风格体现在画面的组织方式里，而不是贴上纹样、边框或符号。
若参考具体作品，不照搬其中可辨认的角色、物体或场景。
工艺若与视觉来源冲突则改用更适合该风格的材质处理。

【硬底线：以下为数值约束，不可协商】
- 背景：单一均匀纯色 {背景色}。无渐变、无纸纹、无颗粒，
  无米白、奶油、象牙、泛黄、牛皮纸色调，无茶渍与做旧，无浅灰
- 三级文字的字高比例固定为 100 比 22 比 12，第三级在正常观看距离必须可读
- 三级文字统一放在底部文字带内，主体不得与底部文字带重叠，
  每个文字块净空 ≥ 字高的 1/2
- 强调色：单一连续色块，覆盖 ≤ 画面 8%
- 网点与颗粒：仅用于图像内部必要区域，不得进入字形外扩 12px
- 顶部 25% 为连续留白；留白是背景色的直接延续，
  不得被画成纸条、横幅或任何有边缘的实体色块

【软引导：以下交给主题与意图决定，不预设数值】
- 主体与参照物可形成强烈尺度反差，具体倍数由主题决定
- 位置、方向、疏密、间距由表达意图决定
- 不固定左图右字或中央构图

【三组文案】
整张海报里只有一条文字带，它位于画面最底部；下面三组文案全部并且只出现在这条文字带里面，
  画面其余任何位置都不得出现任何文字、字母、数字或符号。
字最大的一行是英文主标题，内容只有 {N} 个词：{英文主标题}，
  这个词在整张海报中只出现一次，除这一处外任何区域不得再出现它
第二行是中文短句，必须恰好是这几个字：{中文短句}
  （依次为：{把这几个字用顿号逐个列出}），一字不多一字不少、字序完全正确；
  承担主要阅读信息，完整、清晰、醒目，表达具体含义，不只是重复英文标题；
第三行是英文短句，内容是：{英文短句}，呼应中文语义但不逐字直译，
  正常观看时清楚可读，不缩成装饰性小字。
主标题若竖排且多于一个词：拆成两个独立竖列左右并列，
  或逐字母声明总数与顺序，且相邻两词的首末字母不得相同。
底部文字带内除三组文案外不得有任何图形、数字、等号、比例符号或其他标注，
  任何图形都不得侵入这条文字带。
三组文案不得包含任何引号字符。
新写的文案不得冒充原作引文。
层级主要通过字重、位置、间距与对齐建立，不依赖悬殊字号。

【负向】
场景内的招牌不出现随机字句。除三组文案外无额外文字、编号、日期或网址。
不显示包裹文案的引号，不添加多余标点。
不出现 logo、水印、相框、墙面样机或手机屏幕展示效果。

【观看路径】
第一眼看清主体与英文主标题；
第二眼通过中文短句理解画面想表达什么；
近看发现与主题有关的细节。
```

其余段落逐字不动：

1. 删掉硬底线中「三级文字统一放在底部文字带内」一条，换成：

2. 底部文字带改两行制：只放中文短句 + 英文短句；
   比例声明改为 `中文短句字高 : 主标题字高 ≈ 22 : 100，英文短句 ≈ 12`。
3. 主体母题是向上动势（飘带、飞升、展翅）时，不写「不得侵入顶部」禁令，

### 一·丙 · 变体：横版 16:9 + 两级文字（主标题 + 副标题，2026-09-23 实测 pass）

> 触发：用户要求**横版 16:9**，且明确「只使用主标题与副标题」两级文字（不是三级），
> 主标题还要穿插于画面。实测稿：主题「自媒体」/ 1960 年代日本现代主义 / 3 色锁定 / 网格+点阵+同心弧线。
> `postcheck.py --track A` → `verdict=pass`，主标题三字被弧线短划线横切仍逐字可辨。

在 §一·乙（主标题穿插型）基础上再做五处改动，其余段落逐字不动：

1. **画幅**：首句改 `设计一张横版 16:9 概念海报`，`size=1536x864`（精确 16:9，**不用后期裁**，
   见 SKILL.md §2 的 2026-09-23 更正）。`{比例}` 别写「竖版 16:9 横版」这种拼接串（fill_meta 不校验语义）。
2. **留白主力挪到右侧**：硬底线「顶部 25% 为连续留白」改
   `画面上方 25% 与画面右侧保持连续留白`。竖版母版的纯顶部留白在 16:9 里会显得空太多，
   而且横版主体+标题全在左侧时，右侧才是真正的呼吸阀。
3. **删掉三条底部文字带条款**（字高 100:22:12 三级比例、底部带统一放置、主体与文字带净空），
   换成 §一·乙 第 1 条的「主标题只出现一次 + 穿插位置」写法，并把比例声明改为
   `副标题字高约为主标题的 12%`。
4. **副标题绝不放右下角**：平台署名水印（右下角「AI生成 / WORKBUDDY」）恒在那儿，
   而 `dewm_imprint.py` 须**同系列多张一起跑**才处理（坑 36），单张交付时它会一直留在画面里。
   实测有效写法：`放在画面右侧、画面高度约三分之二处的安静留白区，与画面下边缘保持一段空白距离`。
5. **用户指定的暖白背景写成 hex**，例如 `色值 #F4F1EA 的极浅暖白`，不要写 `warm / cream / 米白` 色相词
   （硬规则 1；写色相词 = 触发泛黄）。hex 写法实测把模型压在三色内成功，
   且 `postcheck` 报的 `[paper_warm_hint]`（base<240）属**预期**，不是缺陷——别为此重生。

> 关于图形规则：用户要求「主规则 1 种 + 辅助 1~2 种」时，把辅助规则写成**可数约束**
> （`只允许出现在两处——头部轮廓内部、手机屏幕`、`恰好四条等间距弧线`），
> 并用一句 `除这三条之外，不再添加任何其它特效、纹理、噪点、模糊或随机装饰` 收口——
> 实测比写「低密度 / 留白 1/3」这类面积百分比有效得多（硬规则 3）。

### 一·丁 · 变体：图形规则系统型（主规则 1 + 辅助 1~2，2026-09-23 由 §六·丁 实测固化为模板）

> 触发：用户要求**「远看仍能认出主题、近看才发现内部由不同视觉系统构成」**，
> 或明确点名要在「线条／点阵／像素／几何／网格／纹理／模糊／扫描／运动轨迹／结构图／符号化」中
> 挑主规则 + 辅助规则。这类需求原先只能整段手写（§六·丁 就是一例），现在固化为可填模板。
>
> **这是 v5.4 主模板的一个「段落级」变体**：替换【画面】与【硬底线】两段，其余段落逐字不动。

从 v5.4 主模板替换以下三段：

1. **【画面】段尾部追加"唯一的图形规则系统，只许用这三条"**（保留原【画面】段的主题与主体描述）：

   ```
   【唯一的图形规则系统，只许用这三条】
   主规则·{主规则名}：{一句话写清它如何建立主体轮廓}。
   辅助一·{辅助规则名}：只允许出现在{可数的具体位置}；{它承担什么——明暗/空间}。
   辅助二·{辅助规则名}：{可数约束，如恰好 N 条}；{它承担什么——运动/局部强调}。
   除这三条之外，不再添加任何其它特效、纹理、噪点、模糊或随机装饰。
   ```

2. **【硬底线】保留原六条**，另加一条把"复杂集中、外围留白"锁住：
   `复杂变化只允许集中在主体内部与关键转折处；外围保持大面积干净留白，
   不平均填满背景，不添加与主题无关的装饰`。

3. **【观看路径】改为三层递进**（这是本变体的验收口径，写进提示词能显著稳定输出）：
   `第一眼看清完整的主体形象；第二眼发现它由{规则名}拆解重建；
   第三眼看出图形规则与主题含义之间的关系`。

**主规则选项库**（选一，写进 `{主规则名}`）——括号内为「拆解服从含义」的对应关系，**必须写出作用，禁止为效果而效果**：

| 规则 | 建立主体时的用法 | 能表达的含义 |
|---|---|---|
| 网格 | 剪影内部由正交等距小方格构成，格尺度由密变疏 → 渐隐为留白 | 秩序、平台化、被结构化的个体 |
| 点阵 | 轮廓内部用直径连续变化的圆点填出体积 | 明暗、密度、热度、人群 |
| 像素 | 轮廓被量化成方块，边缘成阶梯 | 数字化、转译、失真 |
| 几何 | 主体由基本形（圆/方/三角/弧）拼装 | 结构、理性、被抽象 |
| 线条 | 主体由等距线族勾勒，线距变化承担明暗 | 速度、精密、被测量 |
| 纹理 | 主体内部换成材质纹理，轮廓不动 | 出处、身份、年代 |
| 模糊 | 主体局部被模糊吞掉 | 消失、遗忘、时间 |
| 扫描切片 | 主体被水平切片并错位 | 位移、故障、断裂 |
| 运动轨迹 | 主体带出等距弧线/残影 | 动作、传播、扩散 |
| 结构图 | 主体被拆成剖面与引线 | 内部关系、机制、可解释 |
| 符号化 | 主体局部替换为与其相关的符号 | 语义压缩、标识 |

三条硬规矩（与 §二 填空规则同级）：

1. **主规则建主体，辅助各担一职**——辅助规则要么管明暗、要么管空间、要么管运动/强调，
   不许两条辅助干同一件事，也不许把选项库全用上（**"所有效果同时出现"是明确禁止项**）。
2. **可数约束写法**：把辅助规则写成 `只允许出现在两处——…、…`、`恰好四条等间距弧线`。
   实测比写「低密度」「留白 1/3」这类面积百分比有效得多（硬规则 3）。
3. **主体必须保留最低限度的识别结构**：轮廓、比例、姿态、标志性结构四者至少保三项；
   抽象不能破坏识别，装饰不能取代结构。

**实测状态**：网格（内部结构层）+ 点阵 + 运动轨迹弧线 三规则组合已实测 pass（`§六·丁`，1/1，主标题被弧线横切仍逐字可辨）；
网点/半调在 A 主模板与 C 模板已长期覆盖；像素与网格（多格层）在 E 已覆盖；
**扫描切片、结构图、模糊、线条、纹理、符号化 六项尚无落点**——首次使用按探索模式跑 2–3 张再入库。

## 二、填空规则

| 槽位 | 填什么 | 原则 |
|---|---|---|
| `{视觉风格}` | 流派 / 年代 / 媒介 | 写「瑞士国际主义」「1960s 波兰海报」「浮世绘版画」，**不写具体作品名**；写了也只当抽象转译的参照 |
| `{内容主题}` | 一个抽象名词 | 无常、秩序、速度、光、空、通勤、汛期…… |
| `{表达意图}` | 一句话的瞬间或情绪 | 「早上六点，站台上只有我」这类**具体场景**，不是「表现孤独」这种概念 |
| `{主体形象}` | 由主题衍生的单一形象 | 几何化、去细节、去拟人。细节一多就变插画，尺度感立刻垮掉 |
| `{背景色}` | 纯白或指定纯色 | 默认写「明亮纯白（bright pure white），不是浅灰」—— 瑞士风格等会把底色压成浅灰（坑 9，加强写法待单因素验证）。**只能写中性白**，见 pitfalls |
| `{英文主标题}` | 单个英文大写单词 | **6–9 字母最佳**，要有大量直线与负空间（HABITAT / GRID / VOID / FORCE）。太圆太长（SYMPHONY）会挤爆构图 |
| `{中文短句}` | 7–12 字 | 口语短句、带画面感，不作格言腔 |
| `{英文短句}` | 一行短句 | 与中文**语义呼应不是逐字直译**，在时态/视角/意象上错开 |

三条硬规矩：

1. **不逐字直译** —— 中英文案是语义呼应，不是双语对照表。中文给具象画面，英文给抽象余味（或反之）。
2. **字母可辨认** —— 穿插遮挡是结构手段，不是可读性牺牲。
3. **顶部 25% 留白** —— 整张海报的呼吸阀，任何元素（含标题）都不得侵入。
4. **向上动势要换向** —— 主体母题是向上动势（飘带、飞升、展翅）时，「不得侵入顶部」禁令无效；
   改写主体的动势方向（写法见 §一·乙 第 3 条，坑 14B）。

## 五、满铺型主体的硬底线二选一（2026-09-06 实测结论，操作段）

「背景纯白 + 顶部留白」这两条硬底线**只对孤置型主体成立**。
满铺型主体（巨浪、巨字场景、充满画面的结构）会天然突破：实测浮世绘巨浪把海面铺满下半部、
浪顶侵入顶部留白带（top noise 94.9），背景纯白条款失效。

按主体类型二选一，不能两者都要：

| 模式 | 硬底线组合 | 适用 |
|---|---|---|
| 孤置型 | 纯白背景 + 顶部留白 + 底部文字带 | 巨物/单体/极简 |
| 满铺型 | 场景铺满 + 底部文字带（**放弃**纯白与留白条款） | 巨浪、巨字、沉浸场景 |

**三条图形规则写法（可数，非百分比）**：
主规则网格（剪影内部由正交等距小方格构成，方格自上而下由密变疏、到下边缘消失为留白）＋
辅助点阵（**只允许出现在两处**：头部轮廓内部、手机屏幕）＋
辅助同心弧线（**恰好四条**，以手机屏为圆心，短划线，越外圈越淡，是画面唯一的运动方向）。
结尾用 `除这三条之外，不再添加任何其它特效、纹理、噪点、模糊或随机装饰` 收口。
**这套三段式写法已固化为 §一·丁 变体**（图形规则系统型），下次直接填 §一·丁。

**实测观察**：
- 主标题三字被弧线短划线横切、笔画局部中断，**仍逐字可辨**（`--text ok`）——穿插遮挡与可读性可兼得。
- 三色 hex 锁定生效：画面外沿与主体外无杂色，朱红只落在手机屏、四条弧线与标题局部。
- `preflight` 报坑 16（约 1119 字）但**实测正常出图**；`postcheck` 报 `[paper_warm_hint]`（base=225<240，R-B=15.5）属六色系统的预期底色，非缺陷。
- 水印：`[wm_none]`（amp=0.75 < 1.0 未判可见），未见平台署名叠加——**但这是概率事件，不要依赖**；副标题仍按 §一·丙 第 4 条避开右下角。
- 未完全达成的一项：主标题字高约达画面 30%（模板声明为 1/6），且右侧略挤。**属可接受偏差，非 blocker，不值得为此重生**（生产配额纪律）。
- 观察到的倾向：模型会把「剪影内部不实心」只落在躯干下半（上半仍给纯黑实面），
  视觉上反而更稳；若必须全网格，需要在提示词里对该部位单独重复一次。

## 七、这套模板最适合哪些场景

### 🟢 最适配

| 场景 | 为什么 |
|---|---|
| 展览 / 双年展 / 艺术节主视觉 | 巨物 + 巨字的纪念碑感天生是展览语言；三组文案层级正好对应「主题—阐释—英文索引」 |
| 独立杂志封面与内页专题 | 顶部 25% 留白留给刊名，底部小字留给期号 |
| 专辑 / 演出 / 概念 EP 封面 | 2:3 就是唱片比例；「安静而有力量」正是独立音乐视觉调性 |
| 品牌 Campaign 的 KV 主图 | 双色调易延展到物料系统；无 logo 约束反而方便后期叠品牌位 |
| 书籍封面（社科 / 哲学 / 科幻） | 抽象母题不剧透内容，尺度反差制造「大主题下的个体」隐喻 |
| 概念电影 / 剧集海报（非卡司向） | 适合氛围先行的文艺片、科幻片前期宣发 |
| AI 图像风格基准测试 | 模板变量固定、结构稳定，适合横向对比不同模型对同一母题的还原力 |

### 🟡 可用但需调整

| 场景 | 调整建议 |
|---|---|
| 社媒九宫格 / 手机海报 | 改 4:5 或 1:1；顶部留白 25% → 35%；第三级文字放大一档 |
| 需要放 logo 的商业稿 | 在顶部留白预留 logo 位，别让巨物顶到天头 |
| 横版 Banner / PPT 背景 | 构图逻辑要重写 —— 尺度反差在横幅里会失效。**横版概念海报走 §一·丙 变体**（16:9 + 两级文字，已实测 pass） |

### 🔴 不适用

- 需要真实产品图、人物肖像、美食、衣物的**实拍向**物料（模板强制「无摄影感」）
- 需要 QR 码、日期、地点、票价的**活动执行稿**（模板显式禁掉）
- 高饱和、热闹、促销感的设计（气质相斥）

## 八、使用心得

- **主标题选词决定成败**：6–9 字母、大量直线与负空间的词穿插效果最好。
- **巨物要去细节**：越几何化，穿插时越像建筑结构。
- **极小参照物放主画面之外**，塞进巨物里尺度反差会被吃掉。
- **工艺指令要留退路**：模板里「若与视觉来源冲突则改用更适合该风格的材质处理」这句很关键 ——
  它让敦煌、浮世绘这类非西方印刷传统的母题不会硬套 AM 网点而变廉价。
