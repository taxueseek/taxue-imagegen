# 类型 E · 多格排版（同规格网格组图）

> v1.12 新增（2026-09-12）。来源：第三方 GPT Image 2.5 语料 256 条中的「多格 / sheet」簇（6 条样本）抽骨架。
>
> **与既有类型的边界（先看这个，别混用）**：
>
> | 需求 | 走哪条 |
> |---|---|
> | 同角色跨帧连续叙事（漫剧/绘本） | **类型 D**（双 LOCK + 逐字复用 + 串行出图），不走本类型 |
> | 同一人多视角九宫格人像 | `taxue-photo-studio` M6，不走本类型 |
> | 同一模特多场景时尚拼贴 | `taxue-photo-studio` M7，不走本类型 |
> | **精灵图 / 动作帧图集** | **本类型 E** |
> | **多格集合（邮票组 / 菜单组 / 系列海报 / 表情包）** | **本类型 E** |
> | **角色设定表（character bible sheet）** | **本类型 E** |
>
> 一句话区分：**E 的每一格是独立成品，靠统一规格串成一组；D 的每一帧是同一故事的连续切片。**

## 一、元提示词模板（中文，槽位化）

```
一张【画幅比例】的【成品类型】，内部严格【列数】×【行数】网格排列，共【格数】格。
每格等比例、尺寸一致、间距【间距描述】，格与格之间【分隔方式】。

每格内容规格：【单格取景规则】，确保【一致性锚】在每一格里完全一致。
每格内容依次为：【逐格清单】。

所有格共用【统一风格句】。

成品为平面完整画布，画面填满整个画布。
不出现相框、墙面或桌面的样机拍摄视角，不出现整幅的透视变形与投影。
```

## 二、槽位表

| 槽位 | 写什么 | 取值示例 |
|---|---|---|
| 画幅比例 | 一个比例，不写像素（像素是 `size` 参数） | `1:1`（3×3 常用）/ `16:9`（2×4 常用）/ `9:16` |
| 成品类型 | 这是什么成品 | `像素精灵图集` / `系列海报` / `邮票组` / `角色设定表` / `表情包组` |
| 列数 / 行数 / 格数 | 网格规模 | `4` / `4` / `16`；`3` / `3` / `9`；`2` / `4` / `8` |
| 间距描述 | 格间留白 | `无缝隙、边框像素对齐` / `细窄整齐` / `均匀留白` |
| 分隔方式 | 格与格怎么分 | `白色间隙` / `细线框` / `无边框直接相邻` / `穿孔边缘` |
| 单格取景规则 | 每格怎么取景 | `单格为 128×128 像素的角色动作帧，角色居中、脚底对齐同一水平线` / `全身或接近全身构图` |
| **一致性锚** | 跨格绝对不许变的（**命门，必填**） | `角色造型、配色、比例` / `字体系统、配色板、版式骨架` / `模特妆发与服装` |
| 逐格清单 | 按阅读顺序从左上到右下的每格内容 | `站立、起步、行走1、行走2…`（数量必须等于【格数】） |
| 统一风格句 | 所有格共用的媒介/光/色/质感（句首「所有格共用」已给出，此处填内容） | `同一套 16-bit 像素配色，正上方单一光源，无抗锯齿` |

## 三、硬规则（从语料 6 条样本读出，违反必翻车）

1. **一致性锚必须正面写死。** 语料原文：`每格人物均以全身或接近全身构图为主`、`顔・髪型・衣装・配色・体格を統一`。不写这一句，模型会每格自由发挥，格与格之间漂移。
2. **逐格清单「要么全给，要么全不给」，不要半给。** 语料里给全清单的两条是全库最长的（1104 字 / 1249 字，逐格写名字与图案）；完全不给清单的那条只有 60 字，靠 `各种不同镜头` 交给模型。**要精确控制就逐格写全；不需要精确就整句交给模型。** 半给半不给最容易被模型自由补全成随机拼接。
3. **必须有防样机收口句。** 多格成品最容易被画成「贴在墙上的九张海报照片」或带整幅透视的画框。模板末两句就是防这个，**不可删**（来源见 `size-and-params.md` 同源的第三方规格）。
4. **比例写正文、像素走参数。** 正文只写 `1:1` / `16:9`；具体像素在提交时用 `size` 参数（见 SKILL.md §2）。这与「坑 16 中文长度阈值」也相关——写像素会白占字数额度。
5. **中文模板控制在 430 字以内**（坑 16 实测阈值）。逐格清单很长时（如 16 格），把每格描述压到 4–6 字，或改用英文（B 类型已证英文吃长清单）。
6. **格数与清单条数必须一致。** fill_meta 会做这一步校验，对不上直接报错——这是本类型最容易出的低级错。
7. **精灵图的透明底**走 `transparent-background-image` 的两步法（白底生成 → matting 抠图），不要指望 `background=transparent`。本模板只负责排版，不负责 alpha 通道。

## 四、已验证填法（三条，覆盖三档用途）

### 填法一 · 像素精灵图集（4×4 = 16 帧动作）

```
一张 1:1 的像素精灵图集，内部严格 4×4 网格排列，共 16 格。
每格等比例、尺寸一致、间距无缝隙、边框像素对齐，格与格之间无边框直接相邻。

每格内容规格：单格为 128×128 像素的角色动作帧，角色居中、脚底对齐同一水平线，确保角色造型、配色、比例在每一格里完全一致。
每格内容依次为：站立、起步、行走一、行走二、奔跑一、奔跑二、腾空、落地、攻击一、攻击二、受击、格挡、施法、倒地、起身、胜利。

所有格共用同一套 16-bit 像素配色，正上方单一光源，无抗锯齿。
成品为平面完整画布，画面填满整个画布。
不出现相框、墙面或桌面的样机拍摄视角，不出现整幅的透视变形与投影。
```

## 五、验收口径（出图前锁死）

1. **格数与网格一致**：数一遍总格数、列数、行数
2. **每格等大**：网格线是否均匀，有没有某格被挤压
3. **一致性锚成立**：跨格不该变的（角色/字体/配色）真的没变
4. **清单齐全**：逐格清单有没有漏格或合并
5. **平面成品**：没有相框、墙面、桌面样机视角，没有整幅透视变形
6. 文字类多格（系列海报/邮票）逐格读字，错字按坑 5/12 处理

## 六、尺寸

按 SKILL.md §2 选 `size` 参数。3×3 与 4×4 常用 `1024x1024`（1:1）；2×4 常用 `1536x1024`（3:2，横）或 `1024x1536`（2:3，竖）；宽幅网格可 `1536x1024`。

**注意**：网格越密，单格像素越少，小字越容易糊。9 格以上、且每格带文字的，建议升 `quality` 到 `high`，或把网格降到 2×2。
